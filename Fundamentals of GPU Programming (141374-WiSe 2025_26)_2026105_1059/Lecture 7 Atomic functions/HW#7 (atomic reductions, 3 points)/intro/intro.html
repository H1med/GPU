For a floating point vector of 40MB size:

- Write a CPU implementation of the reduction algorithm (sum of all the
elements). Use it for checking all of GPU outputs!!!

- Write a GPU implementation of the reduction algorithm using the atomic add
functions on one variable in the global memory

- Write a GPU implementation of the reduction algorithm using a “cascaded
algorithm”, use all of the following: fix the number of blocks to the
approximate number of active blocks on your GPU (estimate it from the
number of the SMs on your GPU and occupancy), sub reduce on the thread
level using registers, each thread processing multiple elements (aggregation
and coarsening), sub reduce on the block level using the atomic add functions
in the shared memory (privatization), finally reduce on the grid level in the
global memory.
